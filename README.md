
# C Midterm Practice

This repository contains my **C programming practice for my 1st-semester midterm**.

I wrote and practiced the programs myself while learning the fundamentals of C, including:

* Data types and operators
* Conditional statements
* Switch and `goto`
* Loops
* Pattern programs
* Functions
* Basic problem-solving programs

For some topics, especially **pattern problems and their logic**, I used **GPT to help me understand the approach and reasoning** when I was stuck. I then wrote and practiced the programs myself.

This repository is mainly a record of my **learning and practice**, rather than a collection of polished or production-level code.

> **Learning by writing, making mistakes, understanding the logic, and trying again.**
